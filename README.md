# Slime Chunk Detector 日本語版
Minecraft の **スライムチャンクを判定するツール**です。  
シード値と座標を入力するだけで、スライムチャンクを高速に判定できます。

- ✔ 多機能  
- ✔ 軽量な単体実行ファイル（.exe）  
- ✔ 日本語対応  
- ✔ ゲームバージョン指定可能  
- ✔ 発見したチャンクを txt で保存可能

## 🔒 実行ファイルの安全性と警告への対処

### この実行ファイルについて
このツールは **シード値からスライムチャンクを判定するだけの単機能ツール**です。  
- ネットワーク接続は行いません  

### SmartScreen が表示された場合
Windows の SmartScreen は「新しい実行ファイル」に対して警告を出すことがあります。

以下の手順で実行できます：

1. ダウンロード元が **GitHub Releases** であることを確認  
2. ファイルを右クリック → **プロパティ**  
3. 「**ブロックの解除**」にチェック → OK  
4. 警告画面で「**詳細情報 → 実行**」を選択  

### Smart App Control（スマートアプリコントロール）の回避方法
Windows 11 の Smart App Control は、署名されていない実行ファイルをブロックすることがあります。  
以下の手順で実行を許可できます。

1. **Windows セキュリティ**を開く  
2. **アプリとブラウザー コントロール**を選択  
3. **Smart App Control の設定**を開く  
4. **オフ**に切り替える（再起動が必要）

※ Smart App Control は Windows の保護機能のため、自己責任で設定してください。

---

### Windows セキュリティの除外設定
ウイルスと脅威の防止でこの exe が誤検知される場合、以下の手順で除外できます。

1. **Windows セキュリティ**を開く  
2. **ウイルスと脅威の防止**を選択  
3. **設定の管理**をクリック  
4. **除外の追加または削除**を選択  
5. **除外の追加 → ファイル**から `slime-chunk.exe` を指定

※ 除外設定はセキュリティを弱める可能性があるため、必要な場合のみ設定してください。
