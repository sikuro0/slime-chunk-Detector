# Slime Chunk Detector 日本語版
Minecraft の **スライムチャンクを判定するツール**です。  
シード値と座標を入力するだけで、スライムチャンクを高速に判定できます。

- ✔ 多機能  
- ✔ 軽量な単体実行ファイル（.exe）  
- ✔ 日本語対応  
- ✔ ゲームバージョン指定可能  
- ✔ 発見したチャンクを txt で保存可能

## 📝 使い方
1. Releases から最新版の `slime-chunk.exe` をダウンロード  
2. exe を起動する  
3. シード値や座標を入力してスライムチャンクを確認  
4. 必要に応じて結果を txt で保存

## 🔒 実行ファイルの安全性と警告への対処

### この実行ファイルについて
このツールは **シード値からスライムチャンクを判定するだけの単機能ツール**です。  
- ネットワーク接続は行いません  

### SmartScreen が表示された場合
Windows の SmartScreen は「新しい実行ファイル」に対して警告を出すことがあります。

以下の手順で実行できます：

1. ダウンロード元が **GitHub Releases** であることを確認  
2. ファイルを右クリック → **プロパティ**  
3. 「**ブロックの解除**」にチェック → OK  
4. 警告画面で「**詳細情報 → 実行**」を選択  

### ウイルス対策ソフトの誤検知について
誤検知が出る場合は以下を推奨します：

- VirusTotal にアップロードしてスキャン結果を確認  
- ソースコードを確認して安全性を確認  
- 必要に応じて各ウイルス対策ベンダーへ誤検知報告
