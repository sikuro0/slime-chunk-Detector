## 🔒 Security warnings and how to handle them

### About this executable

This is a **single-purpose tool that only works out slime chunks from a world seed**.

- It makes no network connections

### If SmartScreen appears

Windows SmartScreen sometimes warns about executables it has not seen before.

You can run the file like this:

1. Confirm that you downloaded it from **GitHub Releases**
2. Right-click the file → **Properties**
3. Tick **Unblock** → OK
4. On the warning screen, choose **More info → Run anyway**

### Getting around Smart App Control

Smart App Control on Windows 11 may block executables that are not signed.
You can allow the file to run like this:

1. Open **Windows Security**
2. Select **App & browser control**
3. Open **Smart App Control settings**
4. Switch it to **Off** (a restart is required)

※ Smart App Control is a Windows protection feature, so change it at your own risk.

---

### Adding an exclusion in Windows Security

If Virus & threat protection flags this exe as a false positive, you can exclude it like this:

1. Open **Windows Security**
2. Select **Virus & threat protection**
3. Click **Manage settings**
4. Select **Add or remove exclusions**
5. Choose **Add an exclusion → File** and pick `slime-chunk.exe`

※ An exclusion can weaken your protection, so only add one if you need it.

## 🔒 実行ファイルの安全性と警告への対処

### この実行ファイルについて

このツールは **シード値からスライムチャンクを判定するだけの単機能ツール**です。

- ネットワーク接続は行いません

### SmartScreen が表示された場合

Windows の SmartScreen は「新しい実行ファイル」に対して警告を出すことがあります。

以下の手順で実行できます：

1. ダウンロード元が **GitHub Releases** であることを確認
2. ファイルを右クリック → **プロパティ**
3. 「**ブロックの解除**」にチェック → OK
4. 警告画面で「**詳細情報 → 実行**」を選択

### Smart App Control（スマートアプリコントロール）の回避方法

Windows 11 の Smart App Control は、署名されていない実行ファイルをブロックすることがあります。
以下の手順で実行を許可できます。

1. **Windows セキュリティ**を開く
2. **アプリとブラウザー コントロール**を選択
3. **Smart App Control の設定**を開く
4. **オフ**に切り替える（再起動が必要）

※ Smart App Control は Windows の保護機能のため、自己責任で設定してください。

---

### Windows セキュリティの除外設定

ウイルスと脅威の防止でこの exe が誤検知される場合、以下の手順で除外できます。

1. **Windows セキュリティ**を開く
2. **ウイルスと脅威の防止**を選択
3. **設定の管理**をクリック
4. **除外の追加または削除**を選択
5. **除外の追加 → ファイル**から `slime-chunk.exe` を指定

※ 除外設定はセキュリティを弱める可能性があるため、必要な場合のみ設定してください。
