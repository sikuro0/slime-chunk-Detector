Slime Chunk Detector

概要

Slime Chunk Detector は Minecraft のスライムチャンクを判定するツールです。シングルプレイやサーバーで使用可能で、バージョン指定や結果の保存が可能です。

特徴

軽量 実行ファイル
多機能
日本語対応
バージョン管理済み
ゲームバージョン指定可能
発見箇所をtxtで保存可能

使い方

  1. Releases から最新版の exe をダウンロード
  2. exe を起動する
  3. シード値や座標を入力してスライムチャンクを確認

ダウンロード

最新版をダウンロード Releases ページを開く
ファイル形式: .exe
サイズ: 最新 213KB
※ リリースのタグ名とファイル名に依存します。必要なら Releases のアセット名を修正してください。

実行ファイルの安全性と警告への対処

この実行ファイルについて

このプログラムはシード値からスライムチャンクを判定する単機能ツールです。ネットワーク接続は行いません。ソースコードは GitHub リポジトリで公開しています。

SmartScreen が表示された場合の手順
  1. ダウンロード元を確認：リンクが github.com の Releases であることを確認してください。
  2. プロパティでブロック解除：ファイルを右クリック → プロパティ → 「ブロックの解除」にチェック → 適用。
  3. SmartScreen の詳細から実行：警告画面で「詳細情報」→「実行」を選択して続行できます（自己責任で実行してください）。
ウイルス対策ソフトの誤検知への対処
  • VirusTotal にファイルをアップロードしてスキャン結果を確認する。
  • ソースコードを確認し、問題がないことを示す。
  • 必要であれば主要ベンダーに誤検知を報告する。
最後に（注意）

疑わしい点があれば実行を中止し、Issue でご相談ください。
