SLIME

Slime Chunk Detector

日本語版 配布ページ

v1.0.0

概要

Slime Chunk Detector は Minecraft のスライムチャンクを判定するツールです。 シングルプレイやサーバー運営でスライムスポーンを効率化したい方向けの軽量ツールです。

特徴

軽量 Java 実行ファイル
オフラインで動作
日本語対応
バージョン管理済み

使い方

  1. Releases から最新版の JAR をダウンロード
  2. Java が入っている環境で実行
  3. 座標を入力してスライムチャンクを確認

ダウンロード

最新版をダウンロード Releases ページを開く
ファイル形式: .jar
サイズ: —
※ ダウンロードリンクはリリースのタグ名とファイル名に依存します。
