概要

Slime Chunk Detector は、Minecraft（Java Edition）のスライムチャンクを判定するツールです。 シングルプレイでもサーバーでも使え、ゲームバージョンを指定した判定と、 見つかった座標の保存に対応しています。

特徴

  • 軽量な単体 exeランタイム不要、ダブルクリックで起動
  • 多機能範囲判定・座標検索をまとめて実行
  • 日本語対応v1.3.0 から英語表示にも対応
  • バージョン指定ゲームバージョンごとの判定に対応
  • 結果を保存発見した座標を txt に書き出し
  • オフラインネットワーク通信は一切行いません

使い方

  1. exe をダウンロード

    上のボタン、または Releases ページから最新版を取得します。

  2. exe を起動

    インストールは不要です。保存したファイルをそのまま実行してください。

  3. シード値と座標を入力

    ワールドのシード値、探索する座標の範囲、ゲームバージョンを指定します。

  4. 結果を確認・保存

    スライムチャンクの一覧が表示されます。必要なら txt に書き出せます。

安全性と警告への対処

署名のない個人製の exe は、Windows やウイルス対策ソフトに警告されることがあります。 以下の内容を確認したうえで、必要な場合のみ設定を変更してください。

このプログラムについて

シード値からスライムチャンクを判定するだけの単機能ツールです。ネットワーク接続は行いません。ソースコードは GitHub リポジトリで公開しています。

SmartScreen の「WindowsによってPCが保護されました」が出る場合
  1. 警告画面の「詳細情報」をクリック
  2. 表示された「実行」をクリック

ダウンロード数が少ない新しいファイルに出る警告です。配布元が信頼できるかを必ず確認してください。

Smart App Control でブロックされる場合

Windows 11 の Smart App Control は、署名されていない実行ファイルをブロックすることがあります。

  1. 「Windows セキュリティ」を開く
  2. 「アプリとブラウザー コントロール」を選択
  3. 「Smart App Control の設定」を開く
  4. 「オフ」に切り替える（再起動が必要）

Windows の保護機能のため、自己責任で設定してください。一度オフにすると再度オンにはできません。

ウイルスと脅威の防止で削除される場合
  1. 「Windows セキュリティ」を開く
  2. 「ウイルスと脅威の防止」を選択
  3. 「設定の管理」をクリック
  4. 「除外の追加または削除」を選択
  5. 「除外の追加」→「ファイル」から exe を指定

除外設定はセキュリティを弱める可能性があるため、必要な場合のみ設定してください。

誤検知かどうかを自分で確かめる
  • VirusTotal にファイルをアップロードしてスキャン結果を確認する
  • GitHub のソースコードを読んで動作を確認する
  • 必要であればベンダーに誤検知として報告する

疑わしい点があれば実行を中止し、Issue でご相談ください。
