Slime Chunk Detector

日本語版 配布ページ

概要

Slime Chunk Detector は Minecraft のスライムチャンクを判定するツールです。 シングルプレイやサーバーで使用可能です。また、バージョン指定も可能です。

特徴

軽量 実行ファイル
オフラインで動作
日本語のみ対応
バージョン管理済み
ゲームバージョン指定可能
発見した箇所をtxtで保存可能

使い方

  1. Releases から最新版の exe をダウンロード
  2. exe を起動する
  3. シード値や座標を入力してスライムチャンクを確認

最新版をダウンロード Releases ページを開く

実行ファイルの安全性と警告への対処

この実行ファイルについて
このプログラムはシード値からスライムチャンクを判定する単機能ツールです。ネットワーク接続は行いません。ソースコードは GitHub リポジトリで公開しています。

検証方法

SHA-256 チェックサムを公開しています。ダウンロード後にチェックサムを照合してください。

SHA256: ここに実際のハッシュを貼ってください

Windows（PowerShell）: Get-FileHash .\slime-chunk.exe -Algorithm SHA256

Linux/macOS: sha256sum slime-chunk.exe

SmartScreen が表示された場合の手順

  1. ダウンロード元を確認：リンクが github.com の Releases であることを確認してください。
  2. チェックサムを照合：上の SHA-256 と一致することを確認します。
  3. プロパティでブロック解除：ファイルを右クリック → プロパティ → 「ブロックの解除」にチェック → 適用。
  4. SmartScreen の詳細から実行：警告画面で「詳細情報」→「実行」を選択して続行できます（自己責任で実行してください）。

ウイルス対策ソフトの誤検知への対応

誤検知が出た場合は以下を推奨します。

  • VirusTotal にファイルをアップロードしてスキャン結果を確認し、問題がないことを示すリンクをページに掲載する。
  • ソースコードを公開している場合はビルド手順を示し、ユーザーが自分でビルドできることを案内する。
  • 必要であれば、主要なウイルス対策ベンダーに誤検知の報告を行う（各社の誤検知報告フォームを利用）。
